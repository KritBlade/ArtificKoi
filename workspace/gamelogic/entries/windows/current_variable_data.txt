High Morals almost always refuses, and a refusal costs her Affection' : '') +

      _traits += k + ': STA ' + bt('Sta', c.Sta) + '·INT ' + bt('Int', c.Int) + '·CHA ' + bt('Cha', c.Cha) +

    // <Personality_Core> [STATE GATES] used to ship the THRESHOLDS and have the narrator re-derive
    // these per girl, per reply, inside <think>. Every INPUT was already on the page — her Hag band
    // in ## TRAITS, the latch and the drive footer in ## PRESENT — so the derivation was the only
    // thing a model was adding, and the only part of it a model could get wrong. Its failure is also

    // nothing ever reported it. Resolve it here; personality_core keeps the LEGEND (what each verdict
    // MEANS to write), because that is semantics, and semantics is the half a model must still do.

        globalThis.MvuHelper.log.child('EJS').warn('STATE GATES: no warmth ceiling for RelationshipStage "' + _stage +

    // ---- (3) SOCIAL CHECK RESULT (PRE_Call_Revisit §4.1) ------

    // <combat_log> in English (live 2026-08-11 the narrator rendered "→ Failure" as "→ 失敗" in a Chinese reply,

          // half-line the narrator would dutifully transcribe as though it had resolved.

        // Duplicated rather than called for the same reason deriveOutcome() below is — this panel must
        // still render with no engine hosted. The derivation fields are MANDATORY here too: RES will skip
        // a check that lacks them, so printing a line for one would hand the narrator a roll to narrate
        // that scores nothing. Correcting HERE is the whole point — the prose transcribes the fixed

      // ---- FWB OPT-IN (P3) — PRE's OTHER roll, rendered into the SAME panel on purpose. It is not a check

        _chk += '[FWB opt-in] on ' + (f.target || '?') + ' — Morals DC ' + dc + ', RawDie ' + die + ' → ' +

      const _PUPPY = { target: 16, stages: ['Dating', 'Girlfriend'], minHagaruro: 61, minMLevel: 30, minLewdness: 50 };

    // whose own 752 characters are transcription rules. By the time the marker rule arrived, the section
    // had already said what the job was. So it becomes a section, and it says the ONE thing that makes it
    // different from everything else on this list: this output goes in the PROSE, not in a patch.
